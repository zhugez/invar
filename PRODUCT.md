# Product

## Platform

Invar is a Rust command-line tool for Linux and macOS. The brand-kit preview is a static web document, not a product web application.

## Product Purpose

Change code. Preserve behavior.

Invar records reviewed commands, separates candidate capture from explicit approval, and compares later command runs with accepted examples.

## Users

The current README addresses project maintainers and people who use coding agents. No customer research or external adoption is claimed.

## Operating Context

A local repository, a terminal, reviewed command arguments, version-controlled configuration, and accepted command observations.

## Capabilities and Constraints

The implemented workflow is init, capture, lock, and verify. Comparison covers exit code, stdout, and stderr byte for byte. A passing result covers configured examples, not all possible behavior. The tool complements tests. Hashes do not authenticate reviewers. Execution is not sandboxed.

## Brand Commitments

The existing name is Invar. The existing tagline is “Change code. Preserve behavior.” Preserve both. The user requested a brand kit without additional aesthetic constraints. The new visual direction is an editor-selected proposal, not a previously approved user preference.

## Evidence on Hand

README.md and docs/specification.md describe implemented behavior. scripts/demo.py and scripts/dogfood.py exercise regression detection and repair. There are no approved customer logos, testimonials, pricing claims, or external case studies.

## Scope of This Request

Create reusable visual assets, voice guidance, design tokens, and a static brand preview. Preserve CLI behavior and existing engineering documentation. Use a static implementation without a frontend framework or runtime dependency.
